Give Hands Foundation – Advanced Website

**PROJECT OVERVIEW**

The Give Hands Foundation website is a WordPress-based web project developed to establish an online presence for a community-focused charitable organisation supporting vulnerable children, families, and communities.

The platform aims to improve access to organisational information, communicate activities and programmes, and provide an online channel through which visitors can engage with the organisation.

Project Objectives

- Establish a professional online presence.
- Present the organisation's programmes and activities.
- Share information about its community initiatives.
- Provide communication channels for visitors.
- Support online donations and donor engagement.

Technologies Used

- WordPress – Content Management System
- PHP – Server-side development
- MySQL – Database management
- HTML – Web page structure
- CSS – Website styling
- JavaScript – Client-side functionality

Main Project Areas

- Organisational information
- Programmes and activities
- Community impact
- Contact and communication
- Donation and donor engagement

Installation

1. Install a local web server such as WAMP.
2. Set up a MySQL database.
3. Place the project files in the local server directory.
4. Configure the WordPress database connection using a secure local configuration.
5. Import the required database and launch the website locally.
